# Praktikum Python: Logika dan Validasi Sistem Informasi

**Repository:** `nayejourney-praktikum-python-logika-si`  
**Bahasa:** Python 3  
**Pemilik:** nayejourney

Project ini mengerjakan enam soal praktik pada modul Pemrograman Python. Nama file dan judul dibuat berbeda dari repository contoh, tetapi ketentuan soal tetap dipenuhi.

## Daftar program

1. `status_akademik.py` menerima data 5 mahasiswa dan menentukan status akademik.
2. `kalkulator_spp.py` menghitung diskon SPP berdasarkan status anak karyawan, IPK, dan pembayaran tepat waktu.
3. `monitor_inventaris.py` memeriksa minimal 8 barang, prioritas restock, nilai inventaris, dan statistik stok.
4. `menu_layanan_kampus.py` menyediakan menu interaktif untuk ketiga studi kasus dengan validasi input.
5. `validasi_mahasiswa.py` memvalidasi NIM, IPK, SKS, dan semester serta menampilkan daftar error.
6. `rekap_logika.py` menghitung persentase mahasiswa aktif, rata-rata diskon, dan persentase barang yang perlu restock dalam bentuk tabel.
7. `jawaban_teori.md` berisi jawaban delapan soal teori.

## Menjalankan program

Pastikan Python 3 sudah terpasang. Buka terminal di folder project, lalu jalankan salah satu contoh:

```bash
python status_akademik.py
python kalkulator_spp.py
python monitor_inventaris.py
python menu_layanan_kampus.py
python validasi_mahasiswa.py
python rekap_logika.py
```

Semua program menggunakan pustaka standar Python, jadi tidak perlu menginstal package tambahan.
